# Anti-Nuke V2
1. Copy `.env.example` to `.env`.
2. Fill DISCORD_TOKEN, CLIENT_ID, GUILD_ID, OWNER_ID.
3. Run `npm install`, then `npm start`.
4. Give the bot View Audit Log, Manage Roles, Manage Channels, Kick Members, Ban Members and Manage Guild.
5. Keep the bot's highest role above roles it needs to manage.
6. Test on a private server first.
